## [0.24.0](https://github.com/Kevin-Lee/scala-hedgehog-extra/issues?q=is%3Aissue%20is%3Aclosed%20-label%3Ainvalid%20milestone%3Am24) - 2026-08-24

## Changes

* [`hedgehog-extra-refined4s`] `genUuid` should not use `java.util.UUID.randomUUID` for `Uuid` generation (#202)
  * `StringGens.genUuid` now generates the most and least significant bits with `Gen.long` and sets the version 4 and IETF variant bits itself, so the generated `UUID`s come from Hedgehog's seed-driven random source and are reproducible and shrinkable.
  * `scala-native-crypto`: removed (no longer required)

* Bump `codecov/codecov-action` from `5` to `7` (#191)
